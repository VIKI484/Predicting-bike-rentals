## Predicting bike rentals 

**Dataset:** UCI Bike Sharing

**Instructions:**

1. Examine how rentals vary by hour, day of the week, season, and weather.
2. Create charts showing trends and relationships.
3. Predict the number of rentals using a regression model.
4. Compare a simple baseline with a more advanced model, such as Random Forest.
5. Measure the error using MAE or RMSE.
6. Discuss which variables are useful when planning bicycle availability.
